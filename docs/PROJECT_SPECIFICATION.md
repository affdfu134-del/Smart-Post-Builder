# Smart Post Builder — Project Specification

## Goal
Create a local-first web MVP for automatically generating professional posts from people data, images, brand assets, templates, and target canvas sizes.

## MVP Scope
- New project creation flow.
- Person data: name, specialty, degree/title, optional notes, image.
- Logo and background upload hooks.
- Date and working-hours fields.
- Auto layout engine starter.
- Basic manual editing through an editor adapter.
- PNG/JPG export contract.
- Local project saving through repository interfaces.
- Extensible template definitions.

## Out of Scope for This Phase
- Production editor implementation.
- Face detection implementation beyond a replaceable crop-provider interface.
- Supabase/backend integration.
- CSV/Excel batch generation.
- Native Android/iOS packaging.
